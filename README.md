# CourseNotes

Веб-приложение для хранения конспектов по учебным курсам.

Студенты и преподаватели создают конспекты по курсам. Приложение формирует краткое содержание конспекта и вопросы для самопроверки.

## Технологии

- Python, Django
- PostgreSQL
- HTML5, CSS3, JavaScript
